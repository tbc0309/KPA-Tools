## Emulator setup guide

### Quickly switch 3DS, PSP, GBA, and GB filters/overlays

[1] After installing the configuration package, open the quick-switch overlay/filter package. It contains packages for 3DS, PSP, GBA, and GB.

[2] Copy the ZIP beginning with PG to internal storage without extracting it. Exit and reopen Pegasus G; it will extract, install, and delete the ZIP automatically.

### NDS emulator setup

[1] Replace lists: skip this if Step 2 already replaced them. Otherwise copy the NDS list from the Roms folder in “【3】覆盖游戏列表（装好游戏后覆盖）”.

[2] Refresh cache: press B to open Pegasus G settings, scroll to the bottom, and reload the media cache.

[3] Grant access: open Accessible Android directories, select +, add the NDS game folder, and exit Pegasus G.

[4] On first launch, select External folder, choose the Drastic folder in internal storage, select Use this folder, select Allow, and grant microphone access while using the app.

[5] The prepared Drastic configuration is restored automatically; no manual reconfiguration is required.

[6] Shortcuts:

- Menu: RC
- Switch upper/lower screens: L2 or touch the upper-left corner
- Fast-forward: R2
- Save state: touch the top center
- Single-screen mode: MODE (small round button to the right of L2)

### 3DS emulator setup

[1] Copy the 3DS list from “【3】覆盖游戏列表（装好游戏后覆盖）” if Step 2 did not already do so, then reload the Pegasus G media cache.

[2] To use Citra-MMJ AnTuTu, open “【0】安装模拟器/【备选】独立模拟器/【4】3DS模拟器 Citra-MMJ 安兔兔版” and follow its instructions.

[3] Citra-MMJ shortcuts:

- Fast-forward: hold RC
- Menu: tap RC
- Switch upper/lower screens: MODE

### PS2 emulator setup

[1] Keep the default first-run options, select Next and Finish, then remove the emulator from recent apps.

[2] Select ≡ → Global Settings → Game List, select +, and add the PS2 or PS2 hack folder containing CHD files.

[3] Open Global Settings → BIOS Settings and select a China BIOS.

[4] Under Controller Settings, enable automatic hiding of virtual controls when an external controller is connected. Under Controller Port 1, use Automatic Mapping, then remap Triangle, Circle, Square, Cross, L2, and R2 manually.

- If it still cannot launch, verify the capitalization of Roms/PS2 and Roms/PS2 hack, reinstall the emulator, and repeat these steps.

### NGC + Wii emulator setup

- This MMJR2-vbi build supports exported settings and overlays.
- The included configuration uses Vulkan, 1.5× resolution, Japanese Wii region/language, hidden on-screen controls, centered touch IR, and motion controls without sensors.

### PSP shortcuts

- Normally, the D-pad acts as the analog stick.
- Touch the left half: map the right stick to D-pad directions for aiming.
- Touch the right half: swipe left/right for D-pad left/right to adjust the camera.
- Temporary D-pad/analog switch: hold L2 or R2.
- Toggle D-pad/analog: MODE.
- Fast-forward: touch the upper-right corner; touch again to restore speed.
- Menu: RC, Select+A, or touch the lower-right corner.
- Save state: Select+L2. Load state: Select+R2.
- Previous/next state slot: Select+L1 / Select+R1.
- Close PSP: Select+B.

### RetroArch shortcuts

- KPA quick menu: touch the upper-right corner.
- Left stick: touch the upper-left corner.
- Exit: L1+R1+Down+Y, or touch the lower-left corner twice.
- Menu: START+SELECT, or touch the lower-right corner.
- Fast-forward: hold R2. Rewind: L2.
- PS1, Saturn, and DS cores retain L2/R2 controller functions; use the quick menu for other shortcuts.

### Pegasus G shortcuts

- Favorite: Select.
- Full-screen: Y or touch the upper-left corner.
- Menu: X or touch the upper-right corner.
- Switch collections: L1/R1. Page up/down: L2/R2.
- Resize tiles: swipe left/right on the game logo while the information panel is visible, or across the center of the top bar in full-screen mode.
