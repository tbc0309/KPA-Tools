## 【重要事项】
1）如后续修改或替换了游戏列表文件metadata.pegasus.txt，需要进入天马G前端的设置页面（前端内按B键），滑到菜单最底部，点击重新加载刷新媒体缓存

2）网盘的"【4】遮罩滤镜快速切换包"内，有方便快速切换配置的文件，在首次完成安装教程后，将PG_*.zip压缩包放入内存，重新进天马G即可快速切换配置

3）RA模拟器，如果左下角出现“XXX手柄未配置”，请退出游戏，单独打开RA，进入"设置--输入--全能手柄按键绑定--端口1控制--保存手柄配置文件"

4）GBA游戏内，如果后台划走RA，此时电池存档不能正常保存，请使用菜单退出和快捷键退出

5）NDS模拟器请参照安装教程的【NDS模拟器设置】，完成替换列表、设置目录的操作

6）PS2模拟器请参照安装教程的【PS2模拟器设置】，完成设置目录、设置Bios、设置手柄的操作

7）网盘的"【6】实用工具APP\【极简桌面】NOVA桌面+壁纸"内，有Nova桌面，恢复备份配置后，在桌面可以双击息屏，或按Home键（顶部L2右边圆键）可以一键打开天马G再按返回桌面

## 【安装教程】

### 【步骤0】修改手柄配置，非常重要！！！

1）进入掌机设置（AYASetting），点击手柄，将手柄风格修改为【Xbox】，并校准手柄

    原AYANEO手柄风格模式在待机唤醒后，RA模拟器会出现ABXY无法控制的问题

2）按右下角的Konkr键呼出快捷栏，进入手柄，将ABXY模式调整为【日式】

3）进入系统设置，点击【系统--手势--系统导航--手势导航】，然后点击【手势导航】右边的齿轮，关闭【滑动即可调用助理】的选项

### 【步骤1】安装天马G前端和配置包

1）安装"【0】安装模拟器"内的MT管理器，后续可以更方便地在MT管理器里安装APK或者拷贝数据

    【1】文件管理器MT管理器 2.17.0.apk

2）安装"【0】安装模拟器"内的天马G前端主程序

    【000】天马G PegasusG 64位 KONKR联名 极速黄金版 蓝框滞留修复  by 蜜仔&Alex&大光圈 20260813.apk

3）下载"【1】安装配置包"内的以下配置包，放入内存或TF卡，不要解压

    PG_天马G_Konkr_Pocket_Advance_定制配置包_2026XXXX.zip

### 【步骤2】安装游戏、覆盖游戏列表
*成功后天马G前端是黑色配色的格子主题，不成功则是红色主题或显示没有游戏*

1）下载天马G的极简或精简游戏整合包，放入内存或TF卡，不要解压
    2026新GBA整合：https://pan.baidu.com/s/10ejv83mBYY2DGWcax2EH9A?pwd=tklm
    极简包：https://pan.baidu.com/s/19t1BIs0jD6Ea_Xm4ZDmEdA?pwd=tklm
    精简包：https://pan.baidu.com/s/1cRU0VuRFSetLJC6IFnu8Iw?pwd=TKLM

2）打开天马G前端并授予权限，会自动解压游戏整合包和配置包

3）将网盘"【3】覆盖游戏列表（装好游戏后覆盖）"内的Roms覆盖到内存目录或TF卡

4）进入天马G前端的设置页面（前端内按B键），滑到菜单最底部，点击重新加载刷新媒体缓存

### 【步骤3】安装模拟器

1）下载本网盘"【0】安装模拟器"内的模拟器

2）必装RetroArch模拟器（RA模拟器）

    安装完毕后打开RA模拟器，请一定要等左下角的base.apk读条走完再关闭模拟器

3）其他模拟器选装（NDS\3DS\N64\NGC\WII\PSP\PS2），装完后请分别打开授予权限

### 【步骤4】覆盖安卓文件夹（三选一）
*成功后单独打开RetroArch模拟器界面是黑黄配色，不成功则是黑白配色*

**方法一（掌机端操作）：**

1）下载"【2】覆盖安卓文件夹"内的覆盖脚本

    安卓目录覆盖脚本_KPA专用.zip

2）将压缩包内的PG_Android文件夹复制到机器内存，不要改变文件结构

3）打开掌机设置（AYASetting），点击"设备--Root脚本"，选择PG_Android目录下的PG_Android.sh，然后运行即可

**方法二（电脑端操作）：**

1）下载"【2】覆盖安卓文件夹"内的Android文件夹，在电脑上覆盖到机器的内存目录

**方法三（掌机端操作）：**

1）用MT管理器删除内存的"Android\data\com.retroarch.aarch64\files\retroarch.cfg"

2）下载"【2】覆盖安卓文件夹"内的Android文件夹，用MT管理器覆盖到内存目录

## 【模拟器设置教程】

### 【快速切换3DS、PSP、GBA、GB滤镜遮罩】

[1] 在安装好配置包以后，进入"遮罩滤镜快速切换包"，3DS、PSP、GBA、GB均有快速切换配置包

[2] 将PG开头的压缩包放入机器内存，不用解压，退出重进天马G即可自动释放安装，并删除压缩包

### 【NDS模拟器设置】

[1] 替换列表：（在【步骤2】已经替换过的此步可以忽略），否则请将网盘"【3】覆盖游戏列表（装好游戏后覆盖）"内的Roms文件夹内的NDS列表覆盖替换（已经替换过的可以忽略），

[2] 刷新缓存：进入天马G前端的设置页面（前端内按B键），滑到菜单最底部，点击重新加载刷新媒体缓存

[3] 授予权限：进入天马G前端的设置页面（前端内按B键），滑到菜单中部，点击"可访问的安卓目录"，点击"+"号，添加NDS游戏目录，然后退出天马G

[4] 设置目录：初次进入Drastic，会弹出目录选择提示，点击提示框右下角"选择外置目录"，进入内存目录的"Drastic"文件夹，点击"使用此文件夹"，点击"允许"，在弹出录音授权页面点击"仅在使用该应用时允许"

[5] 配置设置：

- 此Drastic版本在TianYa大佬和蜜仔大佬的共同努力下，已可以导出配置，且配置文件已由我制作好放入配置包，已自动还原，无需再手动设置一遍

[6] 快捷键介绍：

- 打开菜单：RC
- 切换上下屏：L2 或者 触摸屏幕左上角
- 快进：R2
- 即时存档：触摸屏幕正上方
- 切换单屏：MODE（L2右边小圆键）

### 【3DS模拟器设置】

[1] 替换列表：（在【步骤2】已经替换过的此步可以忽略），将网盘"【3】覆盖游戏列表（装好游戏后覆盖）"内的Roms文件夹内的3DS列表覆盖替换，然后进入天马G前端的设置页面（前端内按B键），滑到菜单最底部，点击重新加载刷新媒体缓存

[2] 如需更换Citra-MMJ安兔兔版：请进入"【0】安装模拟器/【备选】独立模拟器/【4】3DS模拟器 Citra-MMJ 安兔兔版"下载，并按目录下的使用说明安装

[3] Citra-MMJ快捷键介绍：

- 快进：RC（长按）
- 菜单：RC（短按）
- 切换上下屏：MODE（L2右边那颗）


### 【PS2模拟器设置】

[1] 进入PS2模拟器，在初始界面，点击"下一步"默认选项，点击"完成"，将模拟器从后台划走

[2] 设置目录：点击左上角"`≡`"图标，进入"全局设置-游戏列表"选项卡，点右下角的"`+`"图标，添加 PS2 或PS2 hack 游戏所在的目录(有chd文件结尾那一层)

[3] 设置Bios：进入"`全局设置-Bios设置`"选项卡，选择China的bios

[4] 手柄设置：进入以太，点击左上角"`≡`"图标，进入控制器设置，在"`虚拟控制器设置`"里，打开"`使用外部控制器时，自动隐藏虚拟控制器`"选项，在"Controller Poert 1"选项卡里，点击自动映射，但是请重新在下面映射三角圆圈方框叉叉，以及L2和R2，以免自动映射有误

* 设置完毕后，如果仍然无法调用，请检查"`Roms/PS2`"和"`Roms/PS2 hack`"的大小写，并尝试卸载 PS2 模拟器重新安装，并重复[1]-[5]的步骤

### 【NGC+WII模拟器设置】

- 在`爱折腾的胖虎`大佬努力下，本网盘的MMJR2-vbi已可以导出配置，并添加了遮罩功能

- 已做好配置（by B站 `千夏的铲子`）：Vulkan引擎，1.5倍分辨率缩放，WII语言区域设置日语，隐藏虚拟按键，触摸IR红外模拟回中（射击游戏可以触屏控制光标），体感控制不使用传感器

### 【PSP快捷键】

- 正常状态，十字键即为摇杆
- 触摸左半屏幕时：映射右摇杆，功能为十字键方向，方便怪物猎人弓箭瞄准调整弹道
- 触摸右半屏幕时：左滑为左方向键，右滑为右方向键，方便怪物猎人调整视角
- 十字键\摇杆切换（临时）：按住L2或R2
- 十字键\摇杆切换（开关）：点击MODE（顶部L2右侧小圆点）
- 加速：触摸屏幕右上角，再次触摸还原
- 菜单：RC 或 Select+A 或 触摸屏幕右下角
- 即时存档：Select+L2
- 即时读档：Select+R2
- 存档编号-1：Select+L1
- 存档编号+1：Select+R1
- 关闭PSP模拟器：Select+B

### 【RA快捷键说明】

- KPA独家快捷菜单：触摸屏幕右上角展开（快速存读档、存档编号增减、单击快进、连发、长按、自动按键功能）
- 左摇杆：触摸屏幕左上角展开
- RA退出：L1+R1+下+Y 或者 触摸屏幕左下角两次
- RA菜单：START + SELECT 或者 触摸屏幕右下角
- 快进：R2（长按）
- 回溯：L2
- PS1\SS\DS模拟器，保留L2R2控制器功能，可通过触摸右上角快捷菜单面板实现快捷操作

### 【天马G快捷键说明】

- 收藏游戏：select
- 全屏模式：Y 或 触摸屏幕左上角
- 打开菜单：X 或 触摸屏幕右上角
- 切换合集：L1/R1
- 上下翻页：L2/R2
- 调整格子大小：简介栏存在状态在，触摸游戏logo左滑或者右滑；全屏模式下，触摸顶栏中部左滑或者右滑
